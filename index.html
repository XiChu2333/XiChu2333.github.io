UiPath — Agent Observability Bellevue, WA · 2023 – present (intern 2022)

The tracing platform for UiPath’s AI agents. A trace records every step of an agent’s execution — tool calls, memory injections, LLM conversations — as spans; the platform ingests and persists tens of millions of trace requests per day.

  • Trace ingestion & hot layer: producer → Azure Event Hub → consumers → Table Storage. The queue decouples the API from storage, absorbs spikes with back-pressure, and recovers from checkpoints with no data loss. A tenant-scoped partition-key design gives tenant isolation, no write hotspots, and O(1) trace lookups at tens-of-ms latency; optimistic concurrency via ETag; bounded hot retention to control cost.
  • Warm layer (my primary ownership): batch ETL moves traces into Snowflake for permanent retention; multi-layer dbt models turn raw traces into curated metrics — agent consumption/credits, memory calls, loop latency, error rates — behind APIs, dashboards, and user-defined alerts. Cost vs. freshness tuned per table: Dynamic Tables with low TARGET_LAG only where real-time alerting needs it.
  • Real-time trace UX: SignalR/WebSocket notification service on CosmosDB Change Feed pushes new spans to clients as agents run — replaced per-second polling, sharply cutting backend load with sub-second updates.
  • SQL → Snowflake ETL: Azure Data Factory + Change Tracking CDC with 100% row-level completeness, soft-delete tombstones, automatic schema evolution, and daily snapshots for point-in-time restore — replaced a commercial ETL vendor with an in-house pipeline to meet compliance requirements.
  • Correctness as an invariant: root-caused a subtle CDC edge case and built a reconciliation monitor anchored to fixed version boundaries that proves hot-to-warm completeness every cycle.
  • Ecosystem & quality: OpenTelemetry exporter to Microsoft Agent 365; schema-validation platform enforcing data contracts across teams; usage/lineage monitoring that retired large volumes of unused data; Python SQL linter in PR review; daily AI-assisted development (Claude Code, Cursor, Codex).
